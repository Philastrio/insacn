# 조직도·인사이동 관리 공개 릴리스

이 저장소는 조직도·인사이동 관리 프로그램의 설치 파일과 자동 업데이트 파일을 공개하기 위한 릴리스 전용 저장소입니다.

프로그램 소스 코드는 포함하지 않습니다. 설치 파일은 [Releases](https://github.com/Philastrio/insacn/releases)에서 받을 수 있습니다.

## Windows 설치

최신 릴리스에서 `Insa_*_x64-setup.exe`를 내려받아 실행하세요. `SHA256SUMS.txt`에서 파일의 SHA-256 체크섬을 확인할 수 있습니다.

## 자동 업데이트

프로그램은 다음 공개 주소에서 최신 버전 정보를 확인합니다.

`https://github.com/Philastrio/insacn/releases/latest/download/latest.json`
